# Decisions

Hard-to-reverse choices are ADRs in this folder. The template is [0000-template.md](0000-template.md).

Status is PROPOSED until the user agrees, then ACCEPTED. Later work does not treat a PROPOSED ADR as decided.

Game rules stay in `docs/game/` or, once classified, in `docs/product/`. A rule does not become an ADR.

Earlier records remain in `docs/adr/`. Do not renumber them. New decisions start at 0001 in this folder.
